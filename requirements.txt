# They are pinned rather than ranged because a serialised scikit-learn estimator

# model built by a different scikit-learn and could misbehave silently.
#
# `pyproject.toml` keeps the abstract (ranged) dependency metadata for
# `pip install -e .`; this file is the concrete, reproducible environment.
#
# Requires Python 3.12+ (scipy 1.18 and shap 0.52 dropped 3.11).
# Regenerate after upgrading with:  pip freeze > requirements.txt
